# Roadmap

## v1.0 (Current)
- [x] Full screen, webcam, and mic recording
- [x] macOS native system audio loopback (14.2+)
- [x] Local editing (trim, cut, stitch, remove filler words)
- [x] Local AI transcription (whisper.cpp) and summaries (Ollama)
- [x] Cloudflare R2 and self-hosted Hono server sharing paths
- [x] Comments, reactions, analytics, password protection, expiry, CTA overlays

## v1.1
- macOS Code-Signing and Notarization for easier distribution
- Release distributed builds

## v1.2
- Windows and Linux desktop app testing and support

## v1.3

## v1.4
- Team Workspaces with Role-Based Access Control (RBAC) on the Hono server

## v1.5
- SSO / SAML / SCIM integrations for Enterprise self-hosting

## v1.6
- Native Mobile apps (iOS/Android) for viewing and capture

## v2.0
