# Attribution

This project is a fork of and heavily inspired by the amazing [open-loom](https://github.com/jayden9889/open-loom) project by jayden9889, distributed under the MIT license. Fork initialized Jul 2026.

Loomforge extends the original open-loom desktop application with local Ollama AI generation, viewer analytics, custom branding, Cloudflare R2 integrations, and many premium sharing features while keeping the code base fully open-source and MIT-licensed.

## Libraries & Tools Used
- Electron
- React
- Tailwind CSS
- Hono
- better-sqlite3
- ffmpeg-static
- whisper.cpp
- Ollama
